✦ About

Kroc-Sauria is an Android file-sharing client built for simple, seamless transfers between devices.

It supports file and text sharing, QR-based pairing, saved transfer codes, transfer history, and Android integration through a clean Jetpack Compose + Material 3 interface.

🐊 A Croc Fork

Kroc-Sauria is an Android-focused fork of Croc by schollz.

This fork focuses on the Android client experience, introducing:

- Kroc-Sauria branding and mascot
- Refreshed Android interface
- Jetpack Compose + Material 3
- Continued Android client development

The original Croc project and its authors remain credited.

Original project: getcroc.com

---

✦ Features

📤 File & Text Sharing
Send files and clipboard text between devices.

📱 QR Pairing
Quickly connect devices using QR codes.

🔐 Saved Codes
Keep frequently used transfer codes for later.

🕘 Transfer History
View previous transfers.

🔗 Android Integration
Share through Android's share sheet and deep links.

🎨 Material 3
Modern interface built with Jetpack Compose.
